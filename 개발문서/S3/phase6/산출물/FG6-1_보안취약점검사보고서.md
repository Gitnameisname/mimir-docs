**작성일**: 2026-05-18
**Phase**: S3 / Phase 6 / FG 6-1

---

## 1. 검사 범위

OWASP API4:2023 (Unrestricted Resource Consumption) / OWASP A04:2021
(Insecure Design) 의 rate-limit 결함 표면.

## 2. 점검 결과 (Severity × Status)

| # | 영역 | 위험 | 점검 | 상태 |
|---|---|---|---|---|
| S1 | annotations 쓰기 | brute force / abuse | 30/min limit | 차단 |
| S2 | annotations 읽기 | scan / harvesting | 60/min limit | 차단 |
| S3 | contributors 조회 | scan | 60/min limit + private cache 15s | 차단 |
| S4 | notifications polling | DOS (high-freq poll) | 120/min limit | 차단 |
| S5 | notifications mark-read | mass replay | 60/min limit | 차단 |

## 3. 잔존 위험 (운영 권고)

| # | 위험 | 권고 |
|---|---|---|
| R1 | per-IP keying — NAT/공유 IP 환경에서 false positive 가능 | Phase 7 (Valkey 도입) 시 per-user/per-actor key 로 전환 |
| R2 | swallow_errors=True — Valkey down 시 limit 자동 우회 | 의도 (가용성 우선). 운영 모니터링 (Valkey health) 으로 보완 |
| R3 | X-Forwarded-For 스푸핑 | `trusted_proxy_count` 설정 — 별 SEC3-BE-005 |
