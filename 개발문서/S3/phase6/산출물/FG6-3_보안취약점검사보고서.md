# FG 6-3 보안취약점검사보고서 — Content Sanitize

**작성일**: 2026-05-18
**Phase**: S3 / Phase 6 / FG 6-3

---

## 1. 검사 범위

OWASP A03:2021 (Injection — 텍스트 byte layer) / A05:2021 (Security
Misconfiguration — control char 처리 누락).

## 2. 점검 결과

| # | 영역 | 위험 | 점검 | 상태 |
|---|---|---|---|---|
| S1 | null byte | Postgres C-string 종료 / 로그 파서 오류 | write reject | 차단 |
| S2 | BOM 삽입 | 본문 시작 BOM → 검색 mismatch | write reject | 차단 |
| S3 | U+202E RLO override | UI wrapping spoofing (예: `evil.exe` 가 `exe.live` 처럼 표시) | write reject | 차단 |
| S4 | surrogate | UTF-8 표현 불가 → DB 거부 → 500 | write reject (400) | 차단 |
| S5 | ANSI escape sequence | log viewer 색 변경 / 터미널 hijack | response sanitize | 차단 |
| S6 | C0 control (0x01~0x1F, 0x7F) | 텍스트 viewer 오작동 | response sanitize | 차단 |
| S7 | mention snippet 안 ANSI | notification UI 오작동 | enqueue 단계에서 sanitize | 차단 |
| S8 | 10,000 자 초과 | DOS / 저장 부하 | write reject (400) | 차단 |
