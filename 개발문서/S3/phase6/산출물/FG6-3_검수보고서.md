## 4. write/read 정합

- DB 원본 = raw (사용자 의도 보존).
- 응답 직렬화 단계에서만 sanitize 적용 (`_to_response`).
- mention `snippet` 은 응답 시점에 통과되지 않으므로 enqueue 단계에서 한번 적용
  (notifications 응답이 단순 dict-passthrough).
