## 4. 절대 규칙 / 정책 준수 확인

### 4.1 R2 ACL 단일 결정점

- `graph_service.build_graph` 가 documents 의 viewer scope IN 필터를 정본으로 한다. 메타노드 (tag / collection) 는 visible documents 의 메타로 자연 필터.
- 단위 회귀 1건 (`test_meta_node_not_leaked_when_doc_invisible`) — 다른 scope 의 document 가 가진 tag 가 본 viewer 의 그래프에 노출되지 않음.
- 라우터가 `_resolve_viewer_scope_profile_ids(actor)` 헬퍼 (documents_service 정본) 사용 — bypass role (ORG_ADMIN/SUPER_ADMIN) 자동 스킵.

### 4.2 노드 상한 / truncated 정합

- DEFAULT_LIMIT = 500, MAX_LIMIT = 2000 — 단위 회귀 4건 (clamp / truncated / not_truncated)
- truncated 시 별도 count 쿼리로 total_documents 정확 보고 (1건 — `test_truncated_flag_when_extra_returned`)

### 4.3 path 충돌 방지

- `/documents/graph` 가 `/documents/{document_id}` 보다 먼저 매칭 — router.py 에서 documents 보다 앞 include
- 검증: `python -c "from app.api.v1.router import v1_router; ..."` 로 `GET /documents/graph` 가 라우트 list 에 정상 등록 확인 완료

### 4.4 뷰 ≠ 권한 (S3 ⑥)

- 그래프 뷰는 documents.scope_profile_id 필터를 통한 viewer 가시성만 다룸 — 다른 scope 의 document / 그 메타데이터 / 백링크 절대 노출 안 함
- 태그 / 컬렉션 메타노드도 documents 통과 후 자연 필터 — viewer 가 아무 document 도 못 보면 메타노드도 0

### 4.5 어휘 단일 정본 (S2 ⑥ 하드코딩 금지)

- backend: `DEFAULT_LIMIT` / `MAX_LIMIT` / `NodeType` / `EdgeType` Literal 모두 `app.services.graph_service` 단일 정본
- frontend: `DocumentLayout` / `DOCUMENT_LAYOUTS` / `DEFAULT_LAYOUT` 모두 `frontend/src/features/documents/layout.ts` 단일 정본
- 라우터 / 테스트 / LayoutToggle / DocumentListPage 모두 본 모듈 import — string literal 인라인 0

## 5. 보안 / 폐쇄망 검토

### 5.1 본 세션 단위 회귀 (R2)

- ACL 누설 방지 1건 — 다른 scope tag 가 그래프에 노출 안 됨 (`test_meta_node_not_leaked_when_doc_invisible`)
- 백링크 엣지: from/to 모두 visible documents 안에 있는 것만 — 단위 회귀 (`test_backlink_target_invisible_excluded`)

### 5.2 운영자 환경 검증 잔여

task2-4.md §5 폐쇄망 검증 체크리스트 — 모두 운영자 환경 의존:

- [ ] `npm install --prefer-offline` 성공
- [ ] `next build` 후 `.next/static/chunks/` 에 cytoscape 청크 존재
- [ ] 빌드 output 에 외부 CDN fetch 없음
- [ ] 네트워크 차단 상태에서 그래프 페이지 정상 렌더
- [ ] CSP 위반 경고 없음
- [ ] `npm audit --production --audit-level=critical` exit 0

→ 별 라운드 (Step 4 + 6/7/8) 에서 운영자 환경에서 실측. 결과는 별 산출물 `FG2-4_번들검증.md` 에 기록.

### 5.3 admin 그래프 볼 때 truncated 신뢰

- 라우터의 `limit` 쿼리는 FastAPI `Query(ge=1, le=MAX_LIMIT)` 로 강제 — 클라이언트가 큰 limit 요청해도 서버가 상한 강제
- truncated 플래그가 응답에 항상 포함 — 클라이언트가 "더 불러오기" 액션 시 신뢰 가능

### 5.4 timing attack — 다른 scope 존재 누설

- 그래프 응답이 documents COUNT 만 노출 (truncated 시 total_documents) — 다른 scope 문서 수는 노출되지 않음
- 단위 회귀 안에서 검증 (scope=[] 시 0건)
