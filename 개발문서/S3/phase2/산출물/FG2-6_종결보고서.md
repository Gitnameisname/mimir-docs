## 3. 보안 회귀 결과 (task2-6.md §8 보안 보고서 — 4 영역 필수)

### 3.1 zip bomb — 5중 방어

| 방어 | 구현 | 회귀 |
|-----|------|----|
| zip 자체 크기 | `check_zip_byte_size` + 라우터 streaming write | TestZipMetadata.test_check_zip_byte_size_over_limit |
| 엔트리 수 상한 | `inspect_zip` 진입 시 검사 | TestEntryLimit.test_entry_count_exceeds |
| 개별 파일 크기 | `inspect_entry` | TestFileTooLarge.test_single_file_exceeds_limit |
| 총 추출 크기 | `inspect_zip` 누적 검사 | TestZipBomb.test_total_extracted_size_exceeds_limit |
| **압축 비율 100:1** | `inspect_entry` (file_size > compress_size × ratio) | TestZipBomb.test_compression_ratio_exceeds_limit (1MB 0-byte 데이터로 검증) |

### 3.2 path traversal

| 시나리오 | 결과 |
|---------|----|
| `../../etc/passwd` | path_traversal 거부 |
| 절대경로 `/etc/passwd` | 거부 |
| 윈도우 드라이브 `C:\\...` | 거부 |
| null byte `\\x00` | _normalize_path defense-in-depth + Python ZipInfo 자동 truncate |
| NFC 정규화 후 동일 경로 | duplicate_path 거부 |

### 3.3 PII

- **원문 저장 금지** 회귀 — `test_mask_does_not_save_raw` (마스킹 텍스트 + ScanResult.findings 어디에도 raw PII 부재)
- **context 누설 차단** — mask_pii 가 같은 길이 마스크로 in-place 치환 후 findings.masked_snippet 재생성 (한 PII snippet 의 context 에 다른 raw PII 들어가지 않음)
- **false positive 차단** — 주민번호 checksum / Luhn 의무. 임의 13자리 / 잘못된 카드는 거부 회귀
- **`yaml.safe_load` 만 사용** — markdown_to_prosemirror 의 frontmatter 파서가 `safe_load` 호출 (코드 grep 시 `yaml.load(` 0 건)

### 3.4 권한 우회

- **scope_profile_id 강제** — POST /vault-imports 시 Form 필수
- **cancel owner 격리** — repository.update_status 의 `WHERE owner_id=?` 강제 (다른 사용자가 import_id 알아도 cancel 불가)
- **단건 GET _can_access** — owner 본인 또는 ADMIN_ROLES 만. 외인이면 404 (존재 유출 차단)
- **변환 결과 ACL** — vault_import_service 가 최종 documents 생성 시 vault_imports.scope_profile_id 를 documents.scope_profile_id 로 강제 (별 라운드 통합 시점에 적용. 본 1차 dry-run 은 documents 생성 안 함)
