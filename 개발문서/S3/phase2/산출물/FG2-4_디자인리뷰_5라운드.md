## 1. 5 라운드 변경 요약

### 1.1 1차 — 노드 크기·간격·라벨 위치

- 노드 크기 28→44, 라벨 → 노드 아래 + 흰 배경 box (text-background-color/opacity/padding)
- cose-bilkent: idealEdgeLength 80→160, nodeRepulsion 4500→10000, numIter 1500→2500, padding 40, fit:true
- dagre: nodeSep 30→80, rankSep 60→120
- breadthfirst spacingFactor 1.2→1.6
- concentric minNodeSpacing 30→60
- **shouldUseGridFallback** — 엣지 0건 또는 엣지/노드 < 5% 면 grid 자동 전환 (force layout 무의미)

### 1.2 2차 — 줌 컨트롤

- 우상단 4 버튼 toolbar — 확대(+)/축소(−)/Fit/Reset
- 키보드 단축키 `+` / `-` / `0` (input/textarea focus 시 무시)
- ZoomBtn 컴포넌트 — 28×28 / 흰 배경 / hover#f3f4f6 / 한국어 aria-label
- Fit 은 cy.fit(undefined, 40), Reset 은 zoom(1)+center()

### 1.3 3차 — 범례 + hover 강조 + 색상 톤다운

- 좌하단 GraphLegend — 접기 가능 (open state)
- 노드 3 종 (원/사각/다이아) + 엣지 3 종 (실선/대시/점선) 시각 견본 + 한국어 라벨
- 동적 — `?include_tag_nodes` / `?include_collection_nodes` 토글 시 범례도 즉시 반영
- hover 강조: `.hovered` class — sky-500 border 3px + z-index 999 + cursor pointer
- 색상 톤다운: document `#3b82f6` → `#60a5fa`, tag `#fbbf24` → `#fcd34d`, collection `#a855f7` → `#c084fc`

### 1.4 4차 — 4 viewport 실측

| viewport | 결과 |
|---------|----|
| desktop (1440) | ✅ 노드 36 grid 정렬, 줌/범례 모두 정상, 좌우 사이드 패널 |
| narrow (1100) | ✅ 캔버스 자동 축소, 줌 컨트롤 캔버스 안 유지 |
| tablet (900) | ✅ DocumentSidebar 본문 하단 stack, 캔버스 + aside flex-col |
| mobile (480) | 🟡 **별 라운드** — flex-col + height:520 inline 충돌로 캔버스 collapse |

### 1.5 5차 — wrapper/inner 분리 (zIndex 충돌 fix)

- cytoscape 가 mount 시 container children 을 자체 canvas 로 교체 → 줌/범례가 사라지던 문제
- **wrapper div (relative + height + overflow:hidden) + inner div (ref=containerRef, absolute inset:0)** 분리
- 줌/범례/오버레이는 wrapper 직속 자식, cytoscape 는 inner 의 DOM 만 mutate
- 결과: 줌/범례가 cytoscape 마운트 후에도 안정적으로 표시 + zIndex 4/5/6 명시로 오버레이 순서 보장

### 1.6 6차 — 줌아웃 시 텍스트 확대 (사용자 추가 요청)

- 사용자 요청: "줌아웃 시 텍스트는 커지게"
- 1차 시도: `font-size = BASE / zoom` — cytoscape 가 zoom 비례 스케일로 다시 곱해 net 결과 base 유지 (효과 0)
- 핵심: 모델 font-size 를 **화면 픽셀 / zoom** 으로 보정해야 화면 표시 크기 변화
- 최종 수식:
  - 화면 픽셀 (의도): `min(22, BASE * (1 + (1 - zoom) * 1.2))` — zoom 작을수록 점진 증가
  - 모델 font-size: `min(60, 화면 픽셀 / zoom)`
  - text-max-width: `BASE / sqrt(zoom)` — sqrt 보정으로 라벨 겹침 줄임 (1/zoom 직접 적용 시 옆 노드 라벨 겹침)
- 결과 (실측):
  - zoom 1.0 → 화면 11px (base 유지)
  - zoom 0.7 → 화면 15px (1.36x)
  - zoom 0.5 → 화면 18px (1.6x)
  - zoom 0.3 → 화면 22px (clamp 상한)
- `cy.on("zoom", updateLabelFontSize)` 으로 동적 갱신 — 줌 컨트롤/마우스휠/단축키 모두 즉시 반영

## 2. 디자인 결정 요약

| 영역 | 결정 |
|------|----|
