## 3. 절대 규칙 / 정책 준수 확인 (task5-4)

### 3.1 R-06 (위젯 회귀 보호)

- DocumentSidebar 가 5 위젯에 **props 그대로 통과** — 동작 변경 0
  - DocumentAssignControls: `documentId`, `currentFolderId`, `currentCollectionIds`
  - TagChipsEditor: `documentId`, `currentTags`, `baseMetadata`, `onJumpToInlineTag`
  - ContributorsPanel: `documentId`
  - AnnotationsPanel: `documentId`, `selectedAnnotationId`, `onSelectAnnotation`
  - BacklinksPanel: `documentId`
- 비활성 탭은 `hidden` (state 보존) — Pre-flight 결정. unmount 시 위젯 state 손실 방지.

### 3.2 R-04 (좁은 화면에서 사이드바가 본문을 가림 방지)

- 현 단계: desktop 고정 사이드바. mobile (< 768px) 은 본문 하단 stack 으로 자연 배치 (CSS layout 의존)
- drawer / bottom-sheet / FAB 는 별 라운드 (UI 디자인 리뷰 후 결정)

### 3.3 어휘 단일 정본 (S2 ⑥)

- `sidebarTabs.ts` 의 `SidebarTab` Literal + `SIDEBAR_TABS` + `SIDEBAR_TAB_META`
- DocumentSidebar / useDocumentSidebar / 회귀 모두 본 모듈 import. string literal 인라인 0.

### 3.4 ARIA / 키보드 네비

- `role="tablist"` + 5 `role="tab"` + 5 `role="tabpanel"`
- `aria-selected` / `aria-controls` / `id` 매칭
- 키보드 네비: ←/→ 탭 이동 / Home / End (전체 이동) — `nativeEvent.isComposing` 가드
- 비활성 탭의 `tabIndex=-1` (포커스 순환 정합)

### 3.5 URL state 동기화

- URL key: `?sidebarTab=<value>` (DocumentListPage 의 `?layout=` / `?view=` / `?tab=` 와 prefix 충돌 없음)
- default 값 자동 제거 (clean URL)
- replace 사용 (히스토리 누적 안 함)

### 3.6 FG 5-2 양방향 정합

- AnnotationMark click → `selectedAnnotationId` 변화 → wrapper 가 `setActiveTab("annotations")` 자동 호출 + 사이드바 자동 활성화

### 3.7 cross-stack 정합 (헌법 제12조)

- 본 FG 는 frontend 전용. backend 변경 없음.
