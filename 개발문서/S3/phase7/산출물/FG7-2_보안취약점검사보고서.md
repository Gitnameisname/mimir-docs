**대상**: Task 7-2 변경분
**검사 기준**: OWASP Top 10 (2021) + 본 프로젝트 SECURITY.md + 헌법 제22조 (P0 금지)

---

## 1. 검사 항목

| # | 항목 | 결과 | 비고 |
|---|---|---|---|
| 1 | 인증 / 인가 우회 | OK | `should_emit_view` 는 인증된 actor 만 처리. anonymous → False |
| 2 | SQL/NoSQL Injection | OK | Valkey 키는 `make_key()` 가 sanitize. actor_id 는 내부 UUID |
| 3 | XSS / CSRF | N/A | UI 노출 없음 (audit dedup gate) |
| 4 | 권한 escalation | N/A | 호출은 게이트 함수 — 인가 결정 안 함 |
| 5 | Sensitive Data Exposure | LOW | Valkey 키에 actor_id (UUID) 포함. Valkey 자체 ACL 책임 (FG 7-1 인프라 가이드 §3) |
| 6 | Race / TOCTOU | OK | SETNX 원자성. 다중 워커에서 정확히 1건만 emit |
| 7 | DoS — key 폭주 | OK | TTL 윈도우 + per-key auto expire. memory 폭주 자연 차단 |
| 8 | DoS — Valkey 장애로 전체 5xx | OK | fail-open fallback (R-I2). 모든 exception 을 LRU 경로로 swallow |
| 9 | Timing attack | N/A | dedup gate — 시크릿 비교 없음 |
| 10 | logging — 시크릿 노출 | OK | 로그에 actor_id 만. password / token 없음 |
| 11 | 폐쇄망 호환 | OK | `is_valkey_disabled()` 시 정상 동작 (R-I1) |

## 2. P0 / 금지 행위 위반 여부

| 헌법 조항 | 위반 | 검사 |
|---|---|---|
| 제22조 P0 금지 (외부 I/O 무허가, 권한 우회 등) | 없음 | dedup gate 는 외부 I/O 발생 안 함. Valkey 는 internal infra |
| 제17조 외부 문서 명령 실행 | 없음 | actor_id / document_id 는 인증된 호출 컨텍스트 |
| 제24조 장기 메모리 | 없음 | Valkey 는 cache (TTL 자동 만료) — 장기 메모리 아님 |

## 3. 발견 / 권고

### 3.1 발견 — None (1차)

Task 7-2 변경 영역에서 신규 보안 위협 발견 없음.

### 3.2 권고 (별 라운드)

- **R-1**: Valkey ACL 설정 (운영자 책임 — FG 7-1 가이드 §3.3). 본 코드는 ACL 없는 환경에서도 안전하게 동작 (silent fallback).
- **R-2**: actor_id 가 키에 평문 포함되는 점 — 별 위험 아님이나, 운영자가 Valkey 디버그 접근 시 모니터링 권장. SECURITY.md 의 cache-key-naming-policy 와 정합.
