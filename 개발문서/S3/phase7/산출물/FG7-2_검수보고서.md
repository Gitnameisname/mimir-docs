## 5. 보안 / DoS 검토

- **Valkey 키 조작 방어**: `make_key()` 가 whitespace / null byte / `:` segment 분리자 sanitize. `TestMakeKey.test_whitespace_in_part_is_sanitized` ✅
- **actor_id 값 노출**: Valkey 키에 actor_id (UUID) 평문 포함. Valkey 인스턴스 자체가 internal (운영자 ACL 책임). 별 위험 아님.
- **TTL 폭주**: 윈도우 300s + 5000 entry × N actor — 메모리 사용량 제한. 상한 `AUDIT_VIEWED_DEDUP_MAX_ENTRIES` 환경변수.
- **Race condition**: SETNX 원자성 보장. `TestMultiWorkerSimulation` 가 4 워커 동시 호출에서 1건만 emit 검증.
